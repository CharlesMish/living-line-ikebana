# Parasol leaf — arrangement evidence

Made on this branch on November 10, 2026, in headless Chrome 153 with software
WebGL. Not a physical phone, and not a GPU or frame-time measurement.

Every placement, aim, bend, base slide, turn, prune, Keep, Photograph and backup
download went through the app's own controls with real pointer and key input.
`?test=1` was used read-only, to project branch points to screen coordinates and
to confirm which transaction a press had acquired before dragging. No graph data
was authored by hand and nothing was written to storage outside the app.

"The Water Between" is three cuttings in the Two islands layout: two parasol
leaves (`plant-2`, `plant-7`) and one reed (`plant-10`). Edits were turns, one
stalk aim, two neck aims, and one reed cut. Seven parasol stems and four reeds
were seated while choosing; the rest were removed with Edit → Remove, which is
why the ordinal is 11.

The backup was imported into a fresh browser profile on this branch's build,
opened, copied to the working bowl, and pruned once (the young stalk of
`plant-2`); after a reload the working copy held the cut and the kept original
was byte-identical. The same file offered to a build of `668e4a3` is refused
whole with "Unsupported generatorVersion parasol-leaf-v1" and leaves that
Garden unchanged.

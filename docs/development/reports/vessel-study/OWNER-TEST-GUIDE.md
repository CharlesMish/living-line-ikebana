# Owner trial: long bed, separate bowls and finishes

Use the isolated draft PR #65 or unpack the playable ZIP and open `START-HERE.html`. No main merge or deployment is required. Keep a real-world backup of anything important before testing browser storage. Ordinary play and each study use separate storage.

1. **Compare at a constant scale.** Open Original, Compact, Long offset bed and Separate small bowls. Use the same camera preset and the same materials. Full-size stems should stay full-size. Each paired bowl is smaller than Petite; the entire pair is wider than Original. The matched report images keep these differences visible.
2. **Try the long bed in Above.** Drag a reed onto the center, near both ends, then just beyond the thin side. Only the ellipse commits. Spread a few reeds along its length and Aim them outward. The field is deliberately narrow; decide on a physical phone whether it feels precise or frustrating.
3. **Try the separate bowls.** Seat a cutting in each pot. Release an insertion in the empty gap: it must not commit. Slide a base toward the other pot: it must remain in its acquired field. There is no lift/reseat-between-pots gesture yet. Look from Above to confirm empty stage between two distinct ceramic and water surfaces.
4. **Edit and recover.** Toggle the existing protection and overlap controls. Bend, Aim, slide a base, Prune, Undo, cancel a live edit and switch views. Original stock length should survive ordinary shaping, and Undo should restore the prior graph. Protection still covers the existing stem cases; it does not add ceramic or leaf/flower collisions.
5. **Change the finish.** Open More → Vessel. Try Sand/Celadon/Charcoal and Glaze/Stoneware at the same view. Plant positions, planting space and camera must stay unchanged. Stoneware is subtle grain and softer reflections. Reload the current URL to preserve its appearance; saving only the base study link reverts to Sand/Glaze. Both paired bowls share a choice in this prototype.
6. **Test Garden honestly.** Keep a named arrangement such as “Separate bowls - Celadon - Stoneware”; download its backup. Import it in another browser into the SAME named study, and manually select the SAME color/surface or use the full saved URL. Open the actual 3D arrangement, then Make a working copy and reload. Plants and camera should match.

## Restore caveat: the thumbnail is not proof

Current Garden backups contain plant graphs, ordinal, camera and a thumbnail. They contain **no vessel/layout identity and no color/finish settings**. A backup from Separate small bowls / Celadon / Stoneware imported into Compact / Sand / Glaze keeps its original thumbnail and exact plants but reconstructs the destination bowl and finish. Roots may then sit outside the smaller bed. They are deliberately not snapped, scaled or repaired on import.

This mismatch is a confirmed prototype limitation, not successful full-scene portability. To reproduce the original scene, restore into the matching named study and appearance. Do not overwrite the source backup while experimenting. A product migration must add a versioned layout and appearance envelope before these can become portable multi-vessel Garden entries.

The playable ZIP also includes `examples/long-bed-fan-garden.json`. To reopen the report's authored fan, select Long offset bed and Sand/Glaze first, then import this file through Garden. It is a normal Garden backup with the same missing-layout/appearance limitation described above.
